# Shopify Platform

## Overview

I am creating a small fullstack project to add to my software engineer portfolio that will showcase my frontend and backend web developement. The backend, written in Express.js, for the most part is set up to run locally on my machine, I still need to iron out some details. I have also already begun workin using React.js in combination with Boostrap, on the frontend but that is where I want you to take over.

## Your task

Finish the frontend portion of my shopify project using javascript and react. I want the website to feel modern and easy to use. Feel free to completely change any frontend work I have done in /frontend. DO NOT change anything in the backend. If you come up across an issue where your version of the frontend does not work with my backend, please ask me first. You are totally free to use any color scheme and design you feel is good for my project.
